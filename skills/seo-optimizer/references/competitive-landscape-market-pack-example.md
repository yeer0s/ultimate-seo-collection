# Market pack — how to prepare a new market (worked example: Portugal, consumer finance & utilities)

Before P2, write a short market pack into `_method/BRIEF.md` so every agent uses the same authorities.

| Slot | Portugal example |
|---|---|
| Official journal | Diário da República (dre.pt / diariodarepublica.pt) |
| Credit-intermediary register | Banco de Portugal — intermediários de crédito (categories: vinculado / não vinculado / a título acessório) |
| Insurance-distributor register | ASF — distribuidores de seguros (agente / corretor / mediador a título acessório) |
| Payment / e-money institutions | Banco de Portugal — entidades autorizadas |
| Energy regulator + price simulator | ERSE (simulador de preços); switching operator ADENE |
| Telecom regulator + comparator | ANACOM (COM.escolha) |
| Securities regulator | CMVM (investor portal, fund comparators) |
| Competition authority studies | Autoridade da Concorrência |
| Tax authority tools | Portal das Finanças (simulators often behind login) |
| Social security tools | Segurança Social (benefit simulators / eligibility checker) |
| Consumer association | DECO / DECO PROteste (publisher and association are different entities) |
| Complaint index | Portal da Queixa (satisfaction index, resolution rate, category rank) |
| Company registries (free tiers) | Racius, eInforma, Informa D&B (size bands) |
| Domain WHOIS | DNS.pt port-43 |
| Search locale params | Google: `hl=pt-PT&gl=pt`; Bing: `cc=PT&setlang=pt-PT&mkt=pt-PT` |
| Statute anchors for the legal perimeter | credit intermediation regime; insurance distribution regime (IDD transposition) |

Adapting to another market: fill the same slots (journal, each licence register, sector regulators and their
free comparators, competition authority, tax/social tools, consumer association, complaint/review index,
company registry, WHOIS, search locale). Missing slots are early gaps.

Archetypes that recurred and are worth pre-seeding as clusters: tied intermediaries with comparison
front-ends · licensed agents/brokers · state comparators · consumer association (publisher vs association) ·
content brands and creators with calculators · anonymous calculator farms · switching services · supplier
or retailer bundles that remove the need to compare · neobanks as rate setters · AI answer engines ·
foreign consolidators without a local asset.
