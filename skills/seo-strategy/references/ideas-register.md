## How to read a row

Each row stands alone: a hypothesis with a test and a kill condition, never a promise or a traffic forecast. Label cell = one verdict from the fixed vocabulary + one evidence label with counts. Policy cell = a verdict checked 2026-10-11 + the engine-page row behind it. `#N` = Meta Study ledger entry (skill `seo-evidence`). Mowei detail stays a short phrase.

## Tempting, and banned

Shortcuts from popular SEO skills and threads (REPORT §6), never planned, tested or offered. **policy-forbidden** = the shortcut meets the cited row's own condition, so test results do not matter. **house rule** = refused here beyond what the policy says (skill `seo-optimizer` § Hard refusals) `[unvalidated house heuristic]`, not an engine prohibition.

| Shortcut | Verdict | Engine cites |
|---|---|---|
| Scaled AI pages, 100,000-title AI libraries | policy-forbidden when pages are made «without adding value for users» (Google) or «without oversight, quality control, or editorial review» (Bing); reviewed pages with value per URL are not this row | skill `seo-engine-policies` › google §5 row 6; skill `seo-engine-policies` › google-ai §5 row 6; skill `seo-engine-policies` › bing §5 row 6 |
| A page for every low-difficulty keyword | policy-forbidden when the pages are «created to rank for specific, similar search queries» (doorway); difficulty is not the test; a page per distinct intent with its own value is not this row | skill `seo-engine-policies` › google §5 row 2 |
| Synonym-variant cycling to dodge duplicate filters | policy-forbidden | skill `seo-engine-policies` › bing §5 row 2; skill `seo-engine-policies` › naver §5 row 6 |
| PBNs, private link networks | policy-forbidden | skill `seo-engine-policies` › google §5 row 5; skill `seo-engine-policies` › bing §5 row 5 |
