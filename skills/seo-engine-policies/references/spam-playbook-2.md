## Classes 1–4, 6–8, 14: content and on-page (C1–C8)

### C1. Cloaking, incl. content served only to AI crawlers
1. **What and why.** Crawlers get a page built to rank, people get another. A 2026 variant gives AI crawlers a separate "AI version" to win citations.
2. **How.** The server branches on user agent, IP, referrer or device; hacks cloak spam from the owner.
3. **Policy.** Google: cloaking is different content «with the intent to manipulate search rankings and mislead users» (paywall exception: K2); «Inserting text or keywords into a page only when the user agent that is requesting the page is a search engine» [documented: https://developers.google.com/search/docs/essentials/spam-policies, 2026-10-11]; «As long as your dynamic rendering produces similar content, Googlebot won't view dynamic rendering as cloaking»; «Using dynamic rendering to serve completely different content to users and crawlers can be considered cloaking.» [documented: https://developers.google.com/search/docs/crawling-indexing/javascript/dynamic-rendering, 2026-10-11]. Bing, Copilot: «serving materially different experiences to crawlers and visitors» [documented: https://www.bing.com/webmasters/help/webmaster-guidelines-30fba23a, 2026-10-11]. Yandex: «content shown to users is different from the content shown to indexing bots» [documented: https://yandex.com/support/webmaster/en/threat/cloaking, 2026-10-11]. Seznam: «vydávání jiného obsahu robotovi vyhledávače než lidem pro stejnou adresu URL» [documented: https://o-seznam.cz/napoveda/vyhledavani/optimalizace/zakazane-a-nevhodne-techniky/, 2026-10-11]. Naver: «레퍼러나 브라우저의 에이전트명 등 기준으로» ("by referrer or browser agent name") [documented: https://searchadvisor.naver.com/guide/content-abusing, 2026-10-11]. Baidu, others: not addressed; no engine names the AI-crawler-only variant as such.
4. **Detection and penalty.** Google manual action «Cloaking and/or sneaky redirects»; check: «Compare the content fetched by Google to the content seen by a human user» [documented: https://support.google.com/webmasters/answer/9044175, 2026-10-11]. Bot-only hreflang fits Google's own cloaking examples `[practitioner: anonymised sources · single thread · 1 thr / 17 · newest 2020-05]` (PLAYBOOK-technical:3640).
5. **Tells.** Middleware branching on bot user agents; text or links differ between browser and Googlebot-UA fetches; "AI" twins of pages served only to AI user agents; `X-Robots-Tag` varying by user agent `[unvalidated house heuristic]`.
6. **Defence.** Own: fetch each template as browser, Googlebot UA and URL Inspection, and diff (skill `seo-technical` › rendering-and-sitemaps-2). Competitor: same diff, then report. Vendor "AI layer": only if people get the same content.
7. **Evidence.** dodopayments/dualmark spec/content-negotiation.md:43-46,69-77 sends AI crawlers Markdown with noindex on the canonical URL (scout B4.md:70-72); fseixas/super-geo-agent-readiness@references/agent-readiness.md:513 redirects AI crawlers by user agent (scout B4.md:65) `[vendor]`. A Major Spam recovery removed Markdown page copies and hidden redirects `[practitioner: anonymised sources · single thread · 1 thr / 50 · newest 2026-08]` (PLAYBOOK-technical:790).

### C2. Doorways: city and location page factories, one page per query
1. **What and why.** Near-identical pages or domains per city, service or question, funnelling every query variant to one offer.
2. **How.** One template, the variable swapped in; some tools print a "uniqueness" score per page (a tell, line 5).
3. **Policy.** Google: doorways, «created to rank for specific, similar search queries» and «lead users to intermediate pages that aren't as useful as the final destination»; «Having multiple domain names or pages targeted at specific regions or cities that funnel users to one page»; «Creating substantially similar pages that are closer to search results than a clearly defined, browseable hierarchy» [documented: https://developers.google.com/search/docs/essentials/spam-policies, 2026-10-11]. Bing: «Publishing the same or substantially similar content across multiple URLs» [documented: https://www.bing.com/webmasters/help/webmaster-guidelines-30fba23a, 2026-10-11]. Yandex: groups of sites «Created to occupy multiple positions in search results and drive traffic.» [documented: https://yandex.com/support/webmaster/en/yandex-indexing/webmaster-advice, 2026-10-11]. Seznam: «skupina stránek, které obsahují odkazy na jeden konkrétní web» ("pages that all link to one site") [documented: https://o-seznam.cz/napoveda/vyhledavani/optimalizace/zakazane-a-nevhodne-techniky/, 2026-10-11]. Naver: «문장 일부만 바꾼 페이지를 수십 개 이상 발행하는 방식» ("dozens of pages with only part of a sentence changed") [documented: https://searchadvisor.naver.com/guide/content-abusing, 2026-10-11]. Baidu: «控制跨领域采集及站群问题» ("site clusters") [documented: https://ziyuan.baidu.com/wiki/7, 2026-10-11]. Others: not addressed.
4. **Detection and penalty.** Google manual action «Thin content with little or no added value» lists «Doorways» [documented: https://support.google.com/webmasters/answer/9044175, 2026-10-11]. ~95% fall during the August 2026 spam update on ~62,000 city-and-trade pages, no manual action `[practitioner: anonymised sources · single thread · 1 thr / 17 · newest 2026-09]` (PLAYBOOK-technical:4108).
5. **Tells.** Only the place name changes; "hundreds of city pages" with a uniqueness score; footer city-link blocks; a page per question `[unvalidated house heuristic]`.
6. **Defence.** A city page needs local data a user can act on, the rest noindexed or consolidated (Mowei concelho pages: 34 indexable; skill `seo-content` › programmatic-seo). Vendor factory: refuse.
7. **Evidence.** TheSmokeDev/geo-skills skills/token-max-factory/SKILL.md:3,42 (scout B4.md:79); leopard627/fire-your-seo-agency@references/en/aeo.md:18-22, a page per question (scout B1.md:85) `[vendor]`. Clone pages swapping only the city are doorway spam `[practitioner: anonymised sources · single thread · 1 thr / 23 · newest 2017-12]` (PLAYBOOK-general:4112).

### C3. Hidden text and links
1. **What and why.** Text or links only crawlers see, to add keywords or pass link credit. 2. **How.** Colour, size, position or opacity; one-character links.
3. **Policy.** Google: «Using CSS to position text off-screen»; «Setting the font size or opacity to 0»; «Hiding a link by only linking one small character»; allowed: «Accordion or tabbed content that toggle between hiding and showing additional content» [documented: https://developers.google.com/search/docs/essentials/spam-policies, 2026-10-11]. Yandex: «Texts with keywords or phrases that are invisible to users, but visible to indexing bots.» [documented: https://yandex.com/support/webmaster/en/threat/seo-text, 2026-10-11]. Seznam: «skrývání částí textu pomocí CSS nebo obrázků» [documented: https://o-seznam.cz/napoveda/vyhledavani/optimalizace/zakazane-a-nevhodne-techniky/, 2026-10-11]. Naver: «글자색을 배경색과 동일하게 설정하거나» [documented: https://searchadvisor.naver.com/guide/content-abusing, 2026-10-11]. Bing, Baidu, others: not addressed.
4. **Detection and penalty.** Google manual action «Hidden text and/or keyword stuffing»; check: «You can often reveal such text by selecting all the text on the page» [documented: https://support.google.com/webmasters/answer/9044175, 2026-10-11].
5. **Tells.** Select-all reveals text; off-screen blocks; hidden text addressed to AI (A2, [spam-playbook-4](spam-playbook-4.md)) `[unvalidated house heuristic]`.
6. **Defence.** Lint for hidden elements carrying links or keyword lists (tabs are fine); a find may be a hack: H3 in [spam-playbook-3](spam-playbook-3.md) first.
7. **Evidence.** Background-coloured hidden text is to be avoided `[practitioner: anonymised sources · single thread · 1 thr / 153 · newest 2024-02]` (PLAYBOOK-general:5982).

### C4. Keyword stuffing, incl. titles, names and city or phone lists
1. **What and why.** Repeating terms, or swapping a real name for a high-volume keyword, to look relevant.
2. **How.** Keyword lists in text, titles, alt text or footers; "near me" and city strings.
3. **Policy.** Google: «Lists of phone numbers without substantial added value»; «Blocks of text that list cities and regions that a web page is trying to rank for» [documented: https://developers.google.com/search/docs/essentials/spam-policies, 2026-10-11]. Bing: «Excessive repetition, unnatural phrasing, or loading pages with irrelevant keywords can reduce visibility or lead to removal» [documented: https://www.bing.com/webmasters/help/webmaster-guidelines-30fba23a, 2026-10-11]. Yandex: «Long lists of search queries or meaningless, incoherent texts loaded with keywords.» [documented: https://yandex.com/support/webmaster/en/threat/seo-text, 2026-10-11]. Seznam: «nepřirozeně vysoký počet vybraného klíčového slova nebo fráze» [documented: https://o-seznam.cz/napoveda/vyhledavani/optimalizace/zakazane-a-nevhodne-techniky/, 2026-10-11]. Naver: «실제 명칭 대신 검색량이 많은 키워드로 치환하여» ("replacing the real name with a high-volume keyword") [documented: https://searchadvisor.naver.com/guide/content-abusing, 2026-10-11]. Baidu: «严惩网页标题作弊» ("punishes title cheating") [documented: https://ziyuan.baidu.com/wiki/7, 2026-10-11]. Others: not addressed.
4. **Detection and penalty.** Google manual action (C3); «Check <title> tags and alt text for strings of repeated words» [documented: https://support.google.com/webmasters/answer/9044175, 2026-10-11].
5. **Tells.** A brief with a density percentage or a "related terms" quota (folklore; evidence argues against (AVOID)); titles repeating the head term `[unvalidated house heuristic]`.
6. **Defence.** Write for the reader; reject briefs that score repetition.
7. **Evidence.** inhouseseo/superseo-skills skills/write-content/SKILL.md:133 and XuanRanL/loamwright-SEO-Skill@references/audit/scoring-weights.md:52 score density (scout B1.md:35, B2.md:71-72; flagged outdated) `[vendor]`. "Near me" stuffing `[practitioner: anonymised sources · single thread · 1 thr / 25 · newest 2025-09]` (PLAYBOOK-professional:2380).

### C5. Scaled content abuse, AI or human
1. **What and why.** Large low-value page sets sold as "fully automated SEO" or "pSEO", betting volume outruns quality systems.
2. **How.** Bulk generation published unreviewed, spread over sites, "humanised" against AI detectors.
3. **Policy.** Google: «no matter how it's created»; «Using generative AI tools or other similar tools to generate many pages without adding value for users»; «Creating multiple sites with the intent of hiding the scaled nature of the content» [documented: https://developers.google.com/search/docs/essentials/spam-policies, 2026-10-11]; pages per fan-out query «primarily to manipulate rankings or generative AI responses in Google Search violates Google's scaled content abuse spam policy» [documented: https://developers.google.com/search/docs/fundamentals/ai-optimization-guide, 2026-10-11]. Bing: «content generated without oversight, quality control, or editorial review» [documented: https://www.bing.com/webmasters/help/webmaster-guidelines-30fba23a, 2026-10-11]. Yandex: «created using neural networks, machine translation, or template methods» [documented: https://yandex.com/support/webmaster/en/threat/useless-content, 2026-10-11]. Seznam: «automatického generování neužitečného obsahu» [documented: https://o-seznam.cz/napoveda/vyhledavani/optimalizace/zakazane-a-nevhodne-techniky/, 2026-10-11]. Naver: «특정 기술의 활용 여부만으로는 판단하지 않습니다» ("not judged by the tool used alone") [documented: https://searchadvisor.naver.com/guide/content-abusing, 2026-10-11]. Baidu: low-quality pages only (skill `seo-engine-policies` › baidu §5 row 14). Others: not addressed.
4. **Detection and penalty.** Google manual action «Major spam problems»: «aggressive spam techniques such as scaled content abuse, cloaking» [documented: https://support.google.com/webmasters/answer/9044175, 2026-10-11]; moving it elsewhere is circumvention: «Using existing or creating new subdomains, subdirectories, or sites with the intention of continuing to violate our policies» [documented: https://developers.google.com/search/docs/essentials/spam-policies, 2026-10-11]. A Major Spam action followed the content into a new folder (PLAYBOOK-technical:790, C1). ~134,000 AI posts: ~41,000 indexed, then 2,350 `[practitioner: anonymised sources · single thread · 1 thr / 112 · newest 2023-01]` (PLAYBOOK-general:3942).
5. **Tells.** Pages per day as the KPI; "zero manual intervention"; one template on thousands of URLs; "staff" bylines; "humanizer" loops `[unvalidated house heuristic]`.
6. **Defence.** Publish only pages with owned data or first-hand work (skill `seo-content` › publishing-gates). Hit: delete or noindex the set, never move it, then request review. Vendor: refuse.
7. **Evidence.** Fully automated SEO is the agentic layer's top practice, carried by vendor launches `[practitioner: anonymised sources · consensus · 4 thr / 265 · newest 2026-07]` (PLAYBOOK-agentic:2600). fseixas SKILL.md:135 strips punctuation that AI detectors key on, a tell (scout B4.md:66) `[vendor]`.

### C6. Scraped, spun and stitched content
1. **What and why.** Others' content republished, reworded or stitched.
2. **How.** Feed watchers republish within minutes; SERP or Q&A dumps; iframes wrap a site.
3. **Policy.** Google: scraping hosts others' content «with the purpose of manipulating search rankings»; «modify it only slightly (for example, by substituting synonyms or using automated techniques)»; «Stitching or combining content from different web pages without adding value» [documented: https://developers.google.com/search/docs/essentials/spam-policies, 2026-10-11]. Bing: «Modifying or lightly rewriting existing content without new insight or perspective is considered scraping» [documented: https://www.bing.com/webmasters/help/webmaster-guidelines-30fba23a, 2026-10-11]. Yandex: «The content is fully or partially copied from other resources.» [documented: https://yandex.com/support/webmaster/en/threat/useless-content, 2026-10-11]. Naver: «검색 엔진의 검색 결과를 그대로 가져와» ("taking search results as they are") [documented: https://searchadvisor.naver.com/guide/content-abusing, 2026-10-11]. Baidu: «严厉打击恶劣采集» ("strikes malicious scraping") [documented: https://ziyuan.baidu.com/wiki/7, 2026-10-11]. Seznam lists, as unsuitable (*Nevhodné*), not forbidden: keep «výsledky vlastního či převzatého vyhledávání» ("own or copied search results") out of crawling, and «Duplicitní weby» (identical sites on several domains) are penalised but one [documented: https://o-seznam.cz/napoveda/vyhledavani/optimalizace/zakazane-a-nevhodne-techniky/, 2026-10-11]. Others: not addressed.
4. **Detection and penalty.** Google manual action «Thin content» names «scraped content» [documented: https://support.google.com/webmasters/answer/9044175, 2026-10-11]. Copiers deindexed after a copyright notice `[practitioner: anonymised sources · single thread · 1 thr / 149 · newest 2021-07]` (PLAYBOOK-general:402).
5. **Tells.** Your sentences with synonyms swapped, published minutes after yours `[unvalidated house heuristic]`.
6. **Defence.** Victim: N3 in [spam-playbook-5](spam-playbook-5.md). "Rewrite competitor content" tools: refuse.
7. **Evidence.** RSS posts spun within minutes `[practitioner: anonymised sources · single thread · 1 thr / 12 · newest 2024-01]` (PLAYBOOK-professional:1346).

### C7. Sneaky redirects: mobile-only, referrer-conditional, delayed
1. **What and why.** Searchers land somewhere other than the ranked page. 2. **How.** Redirects only for mobile, search visitors, after a delay or on back; often an ad script or a hack.
3. **Policy.** Google: «Showing desktop users a normal page while redirecting mobile users to a completely different spam domain» [documented: https://developers.google.com/search/docs/essentials/spam-policies, 2026-10-11]. Yandex: «created to automatically redirect users to another resource without their consent» [documented: https://yandex.com/support/webmaster/en/yandex-indexing/webmaster-advice, 2026-10-11]. Seznam: «za krátký čas po načtení automaticky přesměrovávají» [documented: https://o-seznam.cz/napoveda/vyhledavani/optimalizace/zakazane-a-nevhodne-techniky/, 2026-10-11]. Naver: «탐지를 회피하기 위해 일정 시간 이후 또는 뒤로가기 동작 시» ("to avoid detection, after a delay or on back") [documented: https://searchadvisor.naver.com/guide/content-abusing, 2026-10-11]. Baidu: «持续打击网络劫持问题» ("hijacking") [documented: https://ziyuan.baidu.com/wiki/7, 2026-10-11]. Bing, others: not addressed.
4. **Detection and penalty.** Google checks redirects that fire «only users coming from Google search, or only users coming from a particular range of IP addresses»; cause named: «Using a script or element to display ads and monetize content that redirect mobile users» [documented: https://support.google.com/webmasters/answer/9044175, 2026-10-11].
5. **Tells.** Destination differs by device or by search click vs typed URL; obfuscated JS or `.htaccess` rules `[unvalidated house heuristic]`.
6. **Defence.** Audit third-party scripts; test from a phone via a search click; hacked: H3. Redirecting to an unrelated page "to keep equity" is not sneaky but risks soft-404 (kgelster/awesome-ecom-skills skills/shopify-redirect-mapping/SKILL.md:29-32; scout B5.md:61) `[vendor]`.
7. **Evidence.** Ranking hijack via misconfigured 302s, said fixed later `[practitioner: anonymised sources · single thread · 1 thr / 57 · newest 2017-02]` (PLAYBOOK-professional:1424).

### C8. Thin affiliate and made-for-ads pages
1. **What and why.** Pages that only pass clicks to merchants or show ads. 2. **How.** Merchant feeds as pages; untested "best X" lists.
3. **Policy.** Google: «product descriptions and reviews are copied directly from the original merchant without any original content or added value»; good: «original product reviews, rigorous testing and ratings» [documented: https://developers.google.com/search/docs/essentials/spam-policies, 2026-10-11]. Bing: «primarily redirect users to retailers without providing original value» [documented: https://www.bing.com/webmasters/help/webmaster-guidelines-30fba23a, 2026-10-11]. Yandex: «through affiliate programs, but don't provide any additional value for the user» [documented: https://yandex.com/support/webmaster/en/yandex-indexing/webmaster-advice, 2026-10-11]. Seznam (MFA): «text s minimální informační hodnotou» [documented: https://o-seznam.cz/napoveda/vyhledavani/optimalizace/zakazane-a-nevhodne-techniky/, 2026-10-11]. Naver: «타 사이트의 글을 복사하거나 짜깁기하지 마세요.» [documented: https://searchadvisor.naver.com/guide/content-basic, 2026-10-11]. Baidu, others: not addressed.
4. **Detection and penalty.** Google manual action «Thin content» names «Thin affiliate pages» [documented: https://support.google.com/webmasters/answer/9044175, 2026-10-11].
5. **Tells.** Merchant copy word for word; no method; the publisher's product always first `[unvalidated house heuristic]`.
6. **Defence.** A comparison site earns affiliate links with method, checked prices and comparisons (skill `seo-content` › comparison-pages).
7. **Evidence.** Self-serving alternatives lists as a drop risk `[practitioner: anonymised sources · single thread · 1 thr / 7 · newest 2026-04]` (PLAYBOOK-professional:724). No scout repo sold thin affiliate pages.
